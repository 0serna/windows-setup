# Windows Setup

Personal automation of preferences for a fresh Windows 11 installation.

## Language

**Windows writing services**:
The per-user Windows facilities that provide typing assistance to compatible applications. They do not control spelling features implemented by individual applications.
_Avoid_: spell checker

**Autocorrection**:
A Windows writing service that automatically replaces text identified as misspelled while it is typed.
_Avoid_: autocorrect

**Spell checking**:
A Windows writing service that identifies and highlights potentially misspelled text without automatically replacing it.
_Avoid_: spell checker, spellchecking
